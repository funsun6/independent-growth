个人独立成长系统｜iPhone 桌面版

一、先说明
这是一个适合 iPhone Safari 添加到主屏幕的网页应用（PWA）。
不是 App Store 原生 App，也不是微信小程序。
首次需要联网打开部署后的 HTTPS 地址；之后可离线打开（首次缓存成功后）。

二、如何运行
1. 将本压缩包中的全部文件部署到一个支持 HTTPS 的静态网站空间。
   可用 GitHub Pages、Cloudflare Pages、Netlify，或你自己的 HTTPS 网站。
   注意：必须把 index.html、app.js、manifest.json、sw.js、两个 icon 文件放在同一目录。
2. 部署完成后，复制网站 HTTPS 地址，在 iPhone 上用 Safari 打开。
3. 等页面完全加载后，点 Safari 底部“分享”图标（方框向上箭头）。
4. 向下找到“添加到主屏幕”。如果没有看到，向下滚动分享菜单。
5. 名称可设为“独立成长”，点击右上角“添加”。
6. 回到 iPhone 桌面，点击“独立成长”图标即可像独立应用一样打开。

三、数据说明
- 每日打卡、每日复盘、周复盘、个人原则和时间设置保存在当前 iPhone 的 Safari 本地存储中。
- 不会自动上传服务器，也不会自动同步到其他设备。
- 清除 Safari 网站数据可能导致记录丢失；重要复盘请自行复制备份。
- 不要将本地存储当作唯一的长期档案。

四、常见问题
- “添加到主屏幕”找不到：确认使用 Safari，而不是微信内置浏览器或其他浏览器。
- 点击桌面图标仍打开浏览器标签页：检查网站是否使用 HTTPS，以及 manifest.json 是否可访问。
- 离线打不开：先联网重新打开一次，等待页面完整加载并完成缓存。
- 修改代码后看不到更新：关闭桌面应用后重新联网打开；如仍未更新，可删除桌面图标后重新添加。

五、部署注意
这是纯静态文件，无需数据库、账号或后端服务。
如果你使用自己的服务器，确保 HTTPS 证书有效，且静态文件 MIME 类型正常。
